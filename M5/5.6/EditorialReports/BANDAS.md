# Bandas utilizadas

- Background
- Title
- Page Header
- Column Header
- Detail 1
- Column Footer
- Page Footer
- Last Page Footer
- Summary

## Comportamiento con datos

- Detail se emite por registro.
- Summary usa REPORT_COUNT y TotalPrecios.
- El total de páginas se obtiene con PAGE_NUMBER evaluado al final del informe.
- Last Page Footer sustituye a Page Footer en la última página.
