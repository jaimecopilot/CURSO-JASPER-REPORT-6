# Librerías para Jaspersoft Studio

El runtime reproducible del curso se resuelve con Maven (`pom.xml`). Esta carpeta documenta las librerías que el alumno puede añadir manualmente al Build Path/Data Adapters en Jaspersoft Studio cuando corresponda.

Versiones de referencia en M3: JasperReports 6.20.0, jasperreports-fonts 6.20.0, Xalan 2.7.2 para XPath/XML, SQLite JDBC 3.44.0.0 y Jackson 2.13.3 (dependencia del runtime JasperReports 6.20.0). No se versionan los JAR binarios en Git.
