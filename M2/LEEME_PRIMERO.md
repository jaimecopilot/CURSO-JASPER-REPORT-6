# M2 — LÉEME PRIMERO

El Módulo 2 continúa el mismo proyecto acumulativo **EditorialReports**.

## Punto de partida

Si has realizado M1, abre **tu propio proyecto resultante de 1.6** y continúa sobre él.

Si necesitas incorporarte directamente a M2, copia el contenido de:

`M1/1.6`

y úsalo como estado inicial para 2.1.

No uses `M2/2.1` para empezar 2.1: esa carpeta contiene la **solución final del punto**.

## Flujo de checkpoints

`M1/1.6 → M2/2.1 → 2.2 → 2.3 → 2.4 → 2.5`

Cada carpeta contiene un estado completo, no un parche.

## Cómo leer la práctica

Cada punto utiliza:

- **Parte A:** construcción/modificación en Jaspersoft Studio.
- **Parte B:** JRXML que representa lo construido.
- **Parte C:** Java que compila, llena y exporta el informe.
- **Parte D:** comprobación del PDF y de la estructura final.

Las dependencias Java se resuelven con Maven. No es necesario construir manualmente un classpath con unos pocos JAR.
