# Dependencias manuales para Jaspersoft Studio/Eclipse

La práctica visual explica cómo copiar los JAR de JasperReports 6.20.0 y añadirlos al Build Path. Para CI y ejecución reproducible se usa Maven mediante `pom.xml`. Se incluye `jasperreports-fonts:6.20.0` para disponer de **DejaVu Sans** de forma portable; los JAR de terceros no se versionan.
